Guide

Halcyon runs the software from a Symbian phone (Symbian^3 and Belle, like the Nokia N8) inside an app that looks like an iPhone home screen. You bring two things: the firmware from your own phone, and the apps you want to run as .sis or .sisx files.

Underneath is EKA2L1, an open-source Symbian emulator. Games run best; productivity and system apps depend on how far EKA2L1 supports them.

Get firmware from your phone

Firmware is Nokia's copyrighted software, so Halcyon cannot include or download it. You dump it once from a phone you own:

  1. Hack the phone so it can run unsigned apps (for Symbian^3 and Belle phones the usual route is Norton Hack or HelloOX).
  2. Install Dumber on the phone, open it, and choose Dump RPKG from the Options menu. You get an .rpkg file (the phone's Z: drive).
  3. With Dumber, dump the ROM as well. You get a .ROM file.
  4. Copy both files to your iPhone (Files app, AirDrop or iCloud Drive) or Mac.

The EKA2L1 wiki has detailed dumping instructions for each phone family.

Add it to Halcyon

You only do this once per device; the firmware stays installed. Use whichever is easiest:

  • Choose files: on the setup screen, pick the ROM and RPKG together, or a single .zip containing both.
  • Open in Halcyon: send the files or the zip to your iPhone with AirDrop, or tap them in Files or Safari, and choose Halcyon. On a Mac, drag them onto the window.
  • Import from a link: paste a link to your own copy. Google Drive files must be shared with "Anyone with the link"; Dropbox links and direct download links work too.
  • Firmware Inbox: put the files in Files › On My iPhone › Halcyon › Firmware Inbox (on a Mac, Settings shows the folder in Finder). Halcyon installs them the next time you open it.

After installing, Halcyon moves the files to Firmware Inbox › Installed, which you can delete to save space. Nothing is uploaded anywhere.

Install on iPhone and iPad

Halcyon is not on the App Store. Install it with a sideloading app, which signs it with your own Apple ID. iOS 18 or later is required.

With SideStore or AltStore (updates included)

  1. Open SideStore or AltStore, go to Sources and add __PAGES__/apps.json.
  2. Find Halcyon in the source and install it.
  3. New releases appear as updates in the same app.

With the IPA file

Download Halcyon.ipa from the releases page and open it with SideStore, AltStore, Sideloadly or TrollStore.

Free Apple IDs re-sign apps every 7 days; SideStore and AltStore do this for you in the background.

Turn on JIT on iPhone and iPad

Symbian apps are 32-bit ARM code and must be translated. With JIT, Halcyon translates blocks of code once and runs them at native speed; without it, the slower interpreter runs every instruction. iOS only allows JIT for sideloaded apps that were started with a debugger attached.

  1. Install StikDebug and complete its one-time pairing.
  2. In StikDebug, choose Enable JIT and pick Halcyon. StikDebug attaches and Halcyon opens with JIT.
  3. In Halcyon, Settings › Performance shows CPU: Dynarmic JIT.

Halcyon checks at every launch whether JIT is actually available and falls back to the interpreter if not, so opening it normally always works.

iOS 26 changed how JIT works on newer devices. If JIT fails there, update StikDebug to its newest version, which handles the iOS 26 method.

Install on a Mac

  1. Download Halcyon.dmg from the releases page, open it and drag Halcyon to Applications.
  2. The first time, Control-click Halcyon and choose Open, unless the release notes say the build is notarized.
  3. Add your firmware when asked.

The Mac app needs an Apple silicon Mac and macOS 15 or later. It always runs with JIT. Use ⌘1, ⌘2 and ⌘3 for Options, Menu and Back, the arrow keys for the navigation key, and type normally into Symbian text fields.

Install Symbian apps

  • Tap + on the home screen and choose one or more .sis or .sisx files.
  • Or share a file to Halcyon from Files, Safari or Mail (Open in Halcyon). On a Mac, double-click it or use File › Install App.
  • New apps land on the next free spot. Touch and hold an icon for Open, Add to Dock, Add to Home Screen and Remove App.
  • Rearrange by dragging icons onto each other or onto the dock.

Your phone's drives live in the Files app under On My iPhone › Halcyon › Halcyon › drives, or in Settings › Files › Show phone storage in Finder on a Mac. Put music, pictures and documents on drive E.

Put Symbian apps on your real Home Screen

iPhone and iPad

Touch and hold an app in Halcyon and choose Add to iPhone Home Screen. You have two options:

  • Add icon to Home Screen creates a small configuration profile with one icon. Safari opens it; tap Allow, then install it in Settings › General › VPN & Device Management. The icon opens the app directly in Halcyon.
  • Shortcuts app: make a shortcut with the Open Symbian App action, pick the app, then Add to Home Screen.

Mac

Choose Add to Applications & Dock, then Create app in Applications. Halcyon makes a launcher app in ~/Applications/Halcyon Apps, much like Parallels does for Windows apps. It appears in Launchpad and Spotlight, and you can drag it to the Dock.

Every route uses the same link, halcyon://launch?uid=…, which you can also use in your own automations.

Widgets and Spotlight

  • Phone Clock: an analog clock with the date.
  • Symbian App: one app, one tap. Edit the widget to choose which.
  • Phone Dock: the four apps in Halcyon's dock.
  • Control Center: an Open Symbian App control for Control Center, the Lock Screen or the Action button.

Installed Symbian apps are also searchable in Spotlight and available to Siri as "Open (app) in Halcyon". Widgets are iPhone and iPad only in this release.

Full Symbian mode

Settings › Full Symbian mode hides the home screen and gives the whole window to the emulated phone, with Options, Menu and Back keys below it. It is experimental: whether the phone's own launcher starts depends on the firmware and on EKA2L1's support for it.

Troubleshooting

  • "Install firmware first": the phone hasn't booted. Add the ROM and RPKG in Settings › Phone › Add firmware.
  • An app installs but no icon appears: some packages add a component or data to another app rather than a new app.
  • A game is slow on iPhone: check Settings › Performance. If it says Interpreter, start Halcyon from StikDebug.
  • The Home Screen profile won't download: Safari must be allowed to open local addresses; try again with Halcyon in the foreground.
  • Switching apps takes a moment: the emulator runs one Symbian app at a time and restarts the phone when you switch.

Still stuck? Open an issue with your device, iOS or macOS version and the app's name.

Building it yourself

You need a Mac with Xcode, brew install xcodegen ninja, and the repository with submodules.

  1. git clone --recursive https://github.com/__REPO__
  2. Build the emulator core: core/scripts/build-core.sh ios and core/scripts/build-core.sh macos. The first run takes a while.
  3. In apple/, run xcodegen generate and open Halcyon.xcodeproj.

Skip step 2 to work on the interface: the apps then build against a demo core with sample apps.
